# MFC Youth Area Management System

An offline desktop application for managing MFC Youth members, chapters, and service assignments through a centralized local database.

The goal of this project is to make youth data management simple, organized, and accessible even without an internet connection.

> This project is currently in **Public Beta v1.0.0** and is actively being improved.

## Features

- Member management
- Chapter management
- Service management
- Member service assignments
- Dashboard with summary statistics
- Offline SQLite database
- Simple and easy-to-use interface
